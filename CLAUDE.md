# Kansei

> Turn vague UI feedback into precise animation and interaction specs.

## Skills

| Command | What it does |
|---------|-------------|
| `/tuning-springs` | Set animation spring values (stiffness, damping, mass) with clear reasoning for each choice |
| `/crafting-shaders` | Build WebGL shaders in React Three Fiber — from CSS prototype to production shader |
| `/timing-rituals` | Design interaction timing and choreography for multi-step UI sequences |
| `/material-physics` | Create realistic digital materials — glass, metal, liquid effects using Fresnel, refraction, and transmission |

## When to use

- Someone says "this animation feels wrong" and you need to figure out the exact spring values
- You're building WebGL effects or shaders in a React Three Fiber project
- You need to choreograph how multiple UI elements animate together (timing, sequencing, delays)
- You want to make a UI element feel like a real material (glass buttons, liquid transitions, metal surfaces)
