# Timing Rituals

Choreography design grounded in the Model Human Processor.

## When to Use
When designing reveals, ceremonies, transitions, or any moment meant to be FELT.

## Core Timings
| Duration | Cycles | Use |
|----------|--------|-----|
| 100ms | 1 perceptual | Instant feedback (tap, hover) |
| 200ms | 2 perceptual | Smooth transition (VIS boundary) |
| 400ms | 4 perceptual | Golden-hold (anticipation peak) |
| 700ms | 7 perceptual | Slow reveal (working memory formation) |
| 1200ms | 12 perceptual | Ritual window (full cognitive engagement) |
| 3000ms | 30 perceptual | Breathing entrainment (meditative induction) |

## Design Rules
1. All durations must be multiples of 100ms (perceptual cycle)
2. Sound persists 7.5x longer than vision — design for the ear
3. Max 7 items visible per section (working memory chunks)
4. Critical decisions show max 3 items (pure WM capacity)
5. 4-8s breathing loops entrain user physiology
